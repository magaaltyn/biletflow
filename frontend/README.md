# BiletFlow frontend

React + TypeScript + Vite + Tailwind. Connected to the FastAPI backend through the Vite proxy (/api -> http://localhost:8000).
See the main README in the project root for setup, demo accounts and the full feature list.

    npm ci
    npm run dev      # http://localhost:5173 (backend must run on :8000)
    npm run build    # type check + production build
